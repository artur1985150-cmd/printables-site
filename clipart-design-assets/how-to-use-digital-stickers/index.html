In short

  • A digital sticker is an image file, most often a PNG with a transparent background, that you place on a digital planner or notes page.
  • In Goodnotes, the cleanest way is an Elements collection: Elements > plus icon > name it > Add Photos or Import from > Create.
  • Single images go in with the Images tool or copy and paste, and any inserted image can be saved to Elements.
  • Stickers printed into a PDF page you imported are part of the paper background and cannot be lassoed; crop them from an image copy instead.
  • Read the licence that came with your stickers before you share the files or sell anything made with them.

To use digital stickers, save the sticker files to your tablet or computer, add them to your note app, then place, resize and rotate them on a page. In Goodnotes the tidiest way is an Elements collection: make a collection, add the sticker images to it, and tap or drag a sticker onto any page. Single images can also go in with the Images tool or plain copy and paste.

The steps below follow Goodnotes' own help pages, since Goodnotes is the app most sticker searches name. Other note apps work on the same principle, with their own buttons; check their help pages for the exact names.

What are digital stickers?

Digital stickers are image files made to decorate digital planners, journals and notes: headers, icons, labels, washi strips, little drawings. They have no adhesive and no paper; you place them on a page the way you would place any picture.

Most come as PNG files. The PNG format supports an optional alpha channel, which is what lets the area around a sticker stay transparent, so a flower sits on your lined page without a white box around it. An image saved without transparency brings its background with it, usually a white box.

Sticker packs usually arrive in one of three forms:

You get What it is Best way in
A ZIP of PNG files One file per sticker Elements collection (Add Photos or Import from)
A .collection file A ready-made Goodnotes Elements collection Import from, inside Elements
A PDF or image of a full sticker sheet Many stickers on one page Images tool, then crop each sticker

How do digital stickers work in Goodnotes?

Goodnotes calls reusable content Elements, saved in collections. A collection can hold images, handwriting, highlighting, shapes and text boxes, and Goodnotes lets you reuse them across documents. That makes it the natural home for stickers: you set a pack up once and reach it from any planner.

Inserted stickers behave like any image on the page. You can move, resize and rotate them, and Goodnotes keeps an image's proportions by default when you resize it, so a sticker does not get stretched by accident.

How to import stickers to Goodnotes as an Elements collection

First get the files onto your device. If the pack is a ZIP, open it in your file manager so the PNGs are unpacked. Then:

  1. Select Elements in the Goodnotes toolbar.
  2. Scroll to the end of the collection list and select the plus icon.
  3. Enter a name in Title, for example "Weekly headers".
  4. Select Add Photos to pick images from Photos, or Import from to pick files from Files.
  5. Select Create.

To add more stickers later, select the collection, choose Edit beside its name and use Add Photos or Import from again. You can also reorder stickers by touching and holding one and dragging it, or remove one with its X icon.

How to use digital stickers on a page

  1. Select Elements in the toolbar.
  2. Choose Stickers, then pick a collection at the bottom of the popover.
  3. Tap a sticker to place it, or drag it onto the page.
  4. Move, resize or rotate it.

Goodnotes also offers a GIFs tab for animated GIPHY content, which needs an internet connection to find and insert a new GIF.

Adding single stickers with Images or copy and paste

For a one-off sticker you don't need a collection:

  • Images tool: select Images in the toolbar, then pick a picture from Photos or choose Insert from to pick a file.
  • Copy and paste: long-press the image in another app, select Copy, then long-press the Goodnotes page and select Paste.

Liked it and want to keep it? Save it to Elements. On iOS, tap the image twice and select Add Element. On Android, Windows and Web, select the image with the Lasso, tap it, then select Add Element. Choose a collection or make a new one.

Why can't I select stickers on a sticker sheet?

Goodnotes' help explains why this happens. When you import a PDF sticker sheet as a notebook, the stickers are printed into the page itself. Goodnotes treats that as the paper background, and images that are part of the background cannot be edited, so the Lasso will not pick them up.

What works instead:

  • Ask for or download the PNG version of the pack, if the seller provides one.
  • Insert the sheet as an image with the Images tool, then crop out one sticker. Goodnotes has a Freehand crop, which lets you draw around an irregular shape. Then save the cropped image to Elements.
  • If the sheet is a Goodnotes notebook where each sticker was placed as its own image, the Lasso will select them and you can copy them to your planner.

Using digital stickers well

  • Keep collections small and named by theme or month, so you are not scrolling through hundreds of icons.
  • Size stickers in the app rather than editing the files: Goodnotes keeps the proportions as you resize.
  • Sharing a collection file is easy in Goodnotes, but read the sticker licence first: it decides whether you may pass the files on.

If you want to sell planner pages decorated with stickers, or make stickers from clipart, read the licence for both. Sticker packs are a special case: the buyer receives each image as a file. The same artwork printed onto an object, such as a sublimated tumbler or a mug, is treated differently in licences such as Canva's. More design files are in our Clipart & Design Assets section.

Questions people ask

What are digital stickers?

Image files made to decorate digital planners, journals and notes. Most are PNG files, because the PNG format supports an alpha channel, which lets the background stay transparent so only the sticker shows on your page.

How do I add stickers to Goodnotes?

Create an Elements collection: select Elements in the toolbar, scroll to the end of the collections, select the plus icon, enter a name, then choose Add Photos or Import from and select Create. To use a sticker, open Elements, choose the collection and tap or drag a sticker onto the page.

Why can't I select the stickers in my sticker book?

If the stickers are printed into a PDF you imported as a notebook, they are part of the page background, and Goodnotes says background images cannot be edited. Use separate PNG files, or bring the sheet in with the Images tool and crop single stickers out of it.

Do digital stickers work on Android or Windows?

Goodnotes describes Elements and image tools for iOS, Android, Windows and Web. On Android, Windows and Web you add an inserted image to Elements by selecting it with the Lasso, tapping it and choosing Add Element.

Can I share a sticker collection with a friend?

Goodnotes lets you share a collection as a file that the other person imports. Check the sticker licence first; it decides whether you may pass the files on.
